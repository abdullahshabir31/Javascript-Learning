# Tip Calculator

A beginner-friendly JavaScript project that calculates the tip amount and total bill.

## 🚀 Features

- Calculate tip percentage
- Display total amount
- Input validation
- Clean interface

- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 Learning Outcome

Learn how to read numeric input, perform calculations, validate form data, and update the webpage dynamically.
