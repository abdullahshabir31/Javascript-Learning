# Age Calculator

A simple JavaScript application that calculates your age from your date of birth.

## 🚀 Features

- Select date of birth
- Calculate current age
- Input validation
- Responsive layout

## 📂 Folder Structure

```text
05-Age-Calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 Learning Outcome

Learn how to work with the JavaScript Date object, calculate age, validate user input, and update the DOM dynamically.
