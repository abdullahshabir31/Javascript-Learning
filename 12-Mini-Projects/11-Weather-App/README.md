# Weather App

A beginner-friendly JavaScript Weather App that displays weather information using demo data.

## 🚀 Features

- Search city
- Display temperature
- Display weather condition
- Easy to understand

## 📂 Folder Structure

```text

```

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 Learning Outcome

Learn DOM manipulation, user input handling, and prepare for integrating real weather APIs.
