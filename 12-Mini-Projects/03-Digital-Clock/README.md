# Digital Clock

A simple JavaScript Digital Clock that displays the current time in real-time.

## 🚀 Features

- Live digital clock
- Updates every second
- 24-hour format
- Beginner-friendly

## 📂 Folder Structure

```text
03-Digital-Clock/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 Learning Outcome

Learn how to use the Date object, setInterval(), DOM manipulation, and real-time UI updates.
