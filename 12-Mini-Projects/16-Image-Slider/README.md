# Image Slider

A simple JavaScript Image Slider that allows users to switch between images.

## 🚀 Features

- Previous & Next buttons
- Multiple images
- Beginner-friendly
- Responsive layout

## 📂 Folder Structure

```text
16-Image-Slider/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 Learning Outcome

Learn arrays, indexing, event handling, and dynamically updating image sources.
