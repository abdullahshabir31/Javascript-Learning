# BMI Calculator

A simple JavaScript BMI Calculator that calculates Body Mass Index based on height and weight.

## 🚀 Features

- BMI calculation
- Simple user interface
- Input validation
- Beginner-friendly

## 📂 Folder Structure

```text
04-BMI-Calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 Learning Outcome

Learn DOM manipulation, form handling, input validation, mathematical calculations, and updating the UI dynamically.
