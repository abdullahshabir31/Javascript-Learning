# Random Color Generator

A simple JavaScript project that generates a random HEX color every time the button is clicked.

## 🚀 Features

- Generate random HEX colors
- Change page background color
- Display generated color code
- Beginner-friendly project

## 📂 Folder Structure

```text
02-Random-Color-Generator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 Learning Outcome

After completing this project, you will understand DOM manipulation, event handling, `Math.random()`, HEX color generation, and dynamic UI updates.
