# 🚀 JavaScript Learning

# 📖 About

This repository contains my JavaScript practice programs, exercises, and mini projects. Every concept is organized into its own folder, and each file represents a specific topic or problem. The repository follows a consistent structure to help track my learning progress and maintain meaningful GitHub commits.
