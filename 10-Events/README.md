# JavaScript Events

This folder contains beginner-friendly examples of JavaScript events and event handling.

## 📚 Topics Covered

- Click Event
- Double Click Event
- Mouse Over Event
- Mouse Out Event
- Key Down Event
- Key Up Event
- Input Event
- Change Event
- Submit Event
- Focus Event
- Blur Event
- preventDefault()
- Event Object
- Event Bubbling
- Event Delegation
- Keyboard Shortcut
