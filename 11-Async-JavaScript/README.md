# JavaScript Async Programming

This folder contains beginner-friendly examples of asynchronous programming in JavaScript.

## 📚 Topics Covered

- Callback Function
- Callback Hell
- Promise
- Promise Chaining
- Async Function
- Await Keyword
- try...catch
- finally
- Fetch API (GET Request)
- Fetch API (POST Request)
- JSON.stringify()
- JSON.parse()
- Local Storage
- Session Storage
- Promise.all()
- Promise.race()
- Promise.allSettled()
